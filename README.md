A Python program that draws a steaming bowl of tonkotsu ramen entirely in code. It renders the bowl, broth, noodles, toppings, and warm table scene into a self-contained PNG using only the standard library.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
